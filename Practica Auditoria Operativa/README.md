# Auditoría Operativa y Diagnóstico de Hipervisores por Línea de Comandos

## Objetivo

Realizar una auditoría operativa de un entorno virtualizado utilizando herramientas nativas de Linux 
para inspeccionar almacenamiento, redes virtuales y consumo de recursos del sistema.

## Actividades realizadas

- Auditoría de almacenamiento lógico mediante LVM.
- Diagnóstico de redes virtuales utilizando Linux Bridge.
- Monitoreo de recursos en tiempo real mediante htop.
- Evaluación básica del estado operativo del sistema.

## Herramientas utilizadas

- Ubuntu Linux
- VirtualBox
- Docker
- LVM2
- bridge-utils
- htop
- OBS Studio
