# Práctica IAM (Identity and Access Management)

## Objetivo

Aplicar el Principio de Menor Privilegio mediante la creación de una cuenta de servicio en Google Cloud, la asignación de permisos de solo lectura y la verificación de la política IAM del proyecto.

## Actividades realizadas
Creación de una cuenta de servicio para auditoría.
Asignación del rol Viewer (solo lectura).
Verificación de la política IAM mediante gcloud CLI.
Validación de la asociación entre la cuenta de servicio y sus permisos.
